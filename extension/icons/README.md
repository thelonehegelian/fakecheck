# Extension Icons

For now, you can use placeholder icons. To create proper icons:

## Quick Option: Use an Icon Generator

1. Go to https://www.favicon-generator.org/ or https://realfavicongenerator.net/
2. Upload a simple design (can be a screenshot of text "FC" or a checkmark)
3. Download the generated icons in different sizes
4. Rename them to:
   - `icon16.png` (16x16 pixels)
   - `icon48.png` (48x48 pixels)
   - `icon128.png` (128x128 pixels)
5. Place them in this `icons/` folder

## Temporary Workaround

For testing, you can:
1. Create simple colored squares in any image editor
2. Save them as PNG files with the correct names
3. The extension will work fine - icons just won't look professional yet

## Icon Design Ideas

- A magnifying glass with a checkmark
- The letters "FC" in a circle
- A shield with a fact-check symbol
- A detective emoji or icon
